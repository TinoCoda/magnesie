Building the Magnésie APK with GitHub Actions

Applies to repository TinoCoda/magnesie · workflow file .github/workflows/android.yml · Created by Tino · 03.10.2026

1. What the workflow does

The workflow “Compiler l'APK Android” runs on a GitHub server (Ubuntu) and turns the code into an installable Android APK. Nothing needs to be installed on your computer.

Step in the fileCommand / actionPurpose
Check out codeactions/checkout@v4Downloads the repository onto the server.
Node 22 + Java 21setup-node, setup-javaInstalls the tools Capacitor (Node) and Gradle (Java, Temurin) need; npm downloads are cached.
Install dependenciesnpm ciInstalls the exact versions from package-lock.json.
Copy web appnpx cap sync androidCopies the www/ folder into the Android project.
Build APK./gradlew assembleDebugCompiles the Android project (inside android/).
Upload resultupload-artifact@v4Stores app-debug.apk as the downloadable artifact magnesie-apk.

Green box = what you download.

3. How to use it

  1. Start a build automatically: push to main (or master). Every push triggers a run.
  2. Start a build by hand: on GitHub open the Actions tab → “Compiler l'APK Android” → Run workflow (enabled by workflow_dispatch).
  3. Follow the run: click the run in the list. Yellow = running, green = success, red = failed. Click a step to read its log; a red step shows the error.
  4. Download the APK: open the finished run, scroll to Artifacts and download magnesie-apk. It is a zip containing app-debug.apk.
  5. Install on the phone: copy the APK to the phone and open it. Android asks once to allow “Install unknown apps” for the browser or file manager you used.
  6. Update the app: edit the code (e.g. www/app.js), commit, push to main, then repeat steps 3–5.
Good to know: this is a debug APK, fine for personal use but not signed for the Play Store. Run #1 on 03.10.2026 completed successfully.
